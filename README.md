# Emoji Battery data

Runtime catalog and image resources for the Emoji Battery Android app.

Source: Emoji_Battery_all supplied by the project owner. Original category names and image files are preserved.

catalog.tsv is UTF-8, with five tab-separated fields per line:
category ID, category display name, item ID, item display name, relative emoji image path.

Each category includes the supplied emoji, thumbnail, battery and photo variants, plus category_icon.png when present.

The Android app downloads the catalog and images over HTTPS. This data is not bundled into its APK.
